# Cuaderno

Cuaderno digital con aspecto de papel electrónico para tabletas con lápiz (pensado para Samsung Galaxy Tab S6 Lite con S Pen).

- Cuadernos escritos a mano con plantillas, capas, lazo, borrador y formas perfectas
- Agenda, reuniones con grabación de audio, biblioteca PDF anotable, recortes y notas rápidas
- Funciona sin conexión y se instala desde Chrome con «Añadir a pantalla de inicio»

Los datos se guardan solo en el navegador del dispositivo (IndexedDB). Este repositorio contiene únicamente el código.
